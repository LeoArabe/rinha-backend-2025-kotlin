# Rinha de Backend 2025 - Kotlin

[Portugues](#portugues) | [English](#english)

---

## Portugues

### Sobre
API de pagamentos de alta performance construida para o desafio Rinha de Backend 2025. Utiliza Kotlin com Spring WebFlux para processamento reativo, MongoDB para persistencia, Redis para cache e Nginx como load balancer.

### Tecnologias
- Kotlin + Spring WebFlux
- MongoDB
- Redis
- Nginx (load balancer)
- Docker + Docker Compose

### Como rodar
```bash
docker compose up --build
```

A API estara disponivel em `http://localhost:9999`.

A imagem Docker tambem esta disponivel no [Docker Hub](https://hub.docker.com/r/leoarabe/rinha-backend-2025-kotlin).

### Status
Projeto completo e funcional.
